# سودوكو برو 🧩

لعبة سودوكو احترافية مع تخزين مشترك على السيرفر (Vercel KV).

## المميزات
- واجهة احترافية (ليلي / نهاري)
- تسجيل دخول بالإيميل وكلمة المرور (الجلسة تُحفظ)
- ترتيب مشترك لكل المستخدمين مع شارات لأول 5
- مسابقة يومية مشتركة + شريط بطل اليوم لمدة 24 ساعة
- كل البيانات محفوظة على Vercel KV

## التشغيل محليًا
```bash
npm install
npx vercel dev
```

## النشر على Vercel (مع التخزين)

1. ارفع المشروع على GitHub.
2. اربطه بمشروع جديد على [vercel.com](https://vercel.com).
3. **مهم**: أنشئ قاعدة KV:
   - من لوحة Vercel → Storage → Create Database → KV
   - اربطها بالمشروع (Connect to Project)
4. اضغط Deploy.

بعد الربط، المتغيرات `KV_REST_API_URL` و `KV_REST_API_TOKEN` تتضاف تلقائيًا.

## الملفات
- `index.html` — الواجهة
- `api/auth.js` — تسجيل / دخول / نقاط
- `api/rank.js` — الترتيب
- `api/comp.js` — بطل المسابقة
- `package.json` — يعتمد على `@vercel/kv`
